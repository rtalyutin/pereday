# Передай · текущая поставка

Frontend v0.2, backend v0.1 и дизайн v0.3 «Альбом дичи». В репозитории подготовлен PostgreSQL API с миграцией, интеграционными проверками и инструкцией запуска. Сохранены 12 PNG, один вклад на полученный снимок, неизменность предков и total_steps=16.

Доработка одной апп: production Node раздаёт `dist/` и `/api/v1` с одного порта; PostgreSQL — отдельный ресурс. Требуются live-сборка, совпадающий slug кампании и разрешённый режим лимита за прокси. Демо и локальный Vite-прокси остаются средствами разработки.

Разрешение: пользователь подтвердил публикацию подготовленного frontend v0.2 и спецификации макета v0.3 в `main` репозитория `rtalyutin/pereday`. Развёртывание сайта в эту операцию не входит.

Критерий передачи: исходники, lockfile, 12 оригинальных PNG, тесты, документация и превью присутствуют; существующие тесты и production-сборка проходят; опубликованное дерево GitHub совпадает с подготовленной версией.

Ограничения: реальный контакт не предоставлен; интеграция с серверным PostgreSQL при конкурентной нагрузке, браузерная приёмка и реальный Figma Player остаются непроверенными. Недостаёт 36 изображений, UI-06 — явно помеченный каркас; D01 не решается молча. D02 и D04 требуют продуктовых решений для внешнего запуска. Frontend v0.2 не полностью синхронизирован с макетом v0.3.
